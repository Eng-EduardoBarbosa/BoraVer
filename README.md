# BoraVer 🎬

Aplicação web para descoberta de filmes e séries com base no humor e nas preferências do usuário.

## ✨ Funcionalidades

- Recomendações de conteúdo por humor
- Busca de filmes e séries
- Filtros por gênero
- Exibição de informações e avaliações dos títulos
- Interface responsiva e interativa

## 🛠️ Tecnologias utilizadas

**Front-end**
- HTML5
- CSS3
- JavaScript

**Integração e dados**
- TMDB API — obtenção de informações sobre filmes e séries

**Back-end**
- Consumo de API externa para obtenção dos dados
- Processamento e exibição das informações no front-end com JavaScript

## 📌 Sobre o projeto

O BoraVer foi desenvolvido para colocar em prática conhecimentos de desenvolvimento web, integração com APIs, manipulação de dados e construção de interfaces dinâmicas, proporcionando uma experiência intuitiva para explorar opções de entretenimento.
